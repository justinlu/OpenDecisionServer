## 解读与后续

- 自建集中，同为英文题目时，英文输入18/24、中文16/24、带空格和连写拼音均12/24；同为中文题目时，英文14/24、中文15/24、带空格拼音13/24、连写拼音14/24。英文输入并不在所有提示条件下领先。
- 自建选择题114/168、布尔题98/168、等级题78/168，错误不限于中文，也涉及否定、转述、时间更正和明确规则；这不是“所有问题都来自中文分词”的证据。
- 数字任务29/72。数字组三种写法改变了结果，但任务本身是阈值判断，不能据此单独归因于tokenizer；需要官方Python同请求对照。
- 全部36个自建家族中，只有2个在所有变体和提示语言下全部正确；8个预测始终一致。一致也可能一直错误。
- 外部测试涉及常识、补全及计算，且变体可能同时改变题目和选项；差异不能只归因于输入语言。作者原始标签未改动。
- 下一步应在相同请求、相同编码预算下比较官方Python与本地Go的token ID和原始logits；再用独立真实脱敏案例验证，不能直接把本次分数外推到线上。
