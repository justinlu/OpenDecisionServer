# 银行自助机具原始文字集 v1

158 条语义：banking-audio-v1 的128条和 banking-credit-audio-v1 的30条。`cases.jsonl` 原样复制其人工编写的 `transcript`、历史、金标及题目；不经过 ASR、不改写、不按两种合成声线重复计数。不包含无语音控制录音或噪声副本，因为它们没有新的文字语义。

`manifest.json` 固定来源及输出 SHA-256。`banking_text.py prepare` 可复核重建。只有 `core` 的130条进入咨询／办理二分类与实际两阶段路由；其余28条澄清、取消、转人工和其他边界内容保留在完整六分类中，避免强塞进二分类。

两阶段沿用此前冻结问题及候选。第一步预测办理才实际调用业务分类。业务单独诊断仅对金标为办理的65条评分，不能回填完整路由。另测大类→细类，子菜单只由模型预测大类决定。信用卡扩展的平铺菜单含15业务＋unknown，旧集平铺仍为10业务＋unknown，分别报告。

已有数据被反复查看过；这是回归评估，不是独立保留集，也不代表真人线上准确率。
