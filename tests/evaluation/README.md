# 中文、英文、数字与拼音决策评测

这是诊断集，不是现实业务准确率保证。测试数据、答案在第一次跑模型前固定；不根据模型结果调整答案，也不把它用作训练集。所有自建文本由本次开发人工逐项编写（AI 助手作者），尚未经独立母语标注团队审校。

## 数据组成

- `custom.jsonl`：504 条。24 个业务语义家族 × 9 种输入形式 × 中英两种题目语言 = 432；12 个纯数字语义家族 × ASCII／全角／前导零三种写法 × 两种题目语言 = 72。
- `seeds.json`：24 个原始语义家族、双语题目和选项、手写拼音与混合文本、答案和理由。九种形式是纯中文、纯英文、带空格拼音、连写拼音、中英混用、中文加数字、英文加数字、中文加拼音、中文英文数字拼音四者混用。拼音不带声调；未覆盖声调符号、声调数字和拼音首字母缩写。
- 业务域：客服路由、账号、电商、物流、日程、情绪、安全规则、证据判断。每域各含 choice、noul、score。覆盖否定、条件、转述、纠正、先后顺序、部分失败、相似选项、无关信息和信息不足。数字任务的规则写在题目中，状态严格是数字字符串，不假设模型知道业务编号的含义。
- `toksuite.jsonl`：TokSuite Chinese 的13个正式配置，共485条；保留原始上游行及其答案。固定版本和每个 Parquet 的 SHA-256 见 `toksuite-manifest.json`。MIT 许可，作者和来源见 `TOKSUITE-NOTICE.md`。

同家族的变体是相关样本。自建集仅36个独立语义家族；外部集围绕40个基础问题。不应把989行当作989个独立真实用户案例，或用逐行独立置信区间夸大结论。自建单个领域／任务组合只有一个语义家族，适合定位具体失效方式，不能估计该业务域总体水平。后续应增加独立作者、真实脱敏流量、长上下文、多轮对话和人工复核。

中文加数字、英文加数字额外加入不影响答案的工单编号，测的是数字噪声鲁棒性；纯数字组测阈值边界与数字书写。二者不等价。自建变体只改变状态，题目与选项语言单独控制；TokSuite 使用作者变体中的题目及选项，不能把其变化归因于状态分词一种因素。外部 TokSuite 还涉及常识和计算，结果与自建上下文判断分开解读；外部原题本身可能有歧义或标注问题，保留作者答案以利复现，错误不能全部归因于分词。

## 重建与运行

Python 3.9+，常规评测不需要第三方包：

```sh
python3 tests/evaluation/build_dataset.py
python3 -m unittest discover -s tests/evaluation -v
# 先启动现有服务，或者使用独立评测端口：
go run ./cmd/ods -http 127.0.0.1:18081 -max-runs 1 -ort-threads 4
# 另一个终端；输出目录必须不存在，避免覆盖历史结果：
python3 tests/evaluation/evaluate.py \
  --url http://127.0.0.1:18081/v1/systemone \
  --output /tmp/ods-language-evaluation
```

可用 `--dataset tests/evaluation/custom.jsonl` 仅评测业务诊断集，或换成另一服务的 `--url` 和 `--model`。对比时固定数据文件、运行参数和版本。不要用相同输出目录重复跑。

重新导入外部源数据时才需要联网和 pyarrow：

```sh
python3 -m venv /tmp/ods-data-import
/tmp/ods-data-import/bin/pip install pyarrow==21.0.0
/tmp/ods-data-import/bin/python tests/evaluation/import_toksuite.py
```

## 判分与输出

- choice 使用返回的选项ID，并校验其属于最高概率选项；noul 使用 P(true)>0.5，正好0.5按 false；score 使用等级概率的 argmax。**不把期望分数四舍五入作为分类结果。** 并列 score 按原等级顺序选第一个。
- HTTP错误、超时、缺字段、非法概率均计为错误，保留在分母；有请求错误时进程退出码为1。正确率低本身不导致非零退出码。本评测用于测量，不给模型设置事后通过线。
- `predictions.jsonl` 包含每行请求、期望答案、预测、概率、错误及耗时；`summary.json` 按来源、输入形式、提示语言、任务和领域细分，含混淆矩阵、macro-F1、均匀猜测参考和固定标签多数类参考。macro-F1 对当前分组声明的全部候选标签取平均（包含没有真例的标签），标签集合保存在 `macro_f1_labels`。
- `paired_vs_chinese` 在相同语义家族、相同题目语言下，比较输入变体与中文原文的退步／恢复；`paired` 的全部正确和预测一致分别统计。一直答错也可能一直一致，二者不能混为准确。
- 总体合并数字仅供描述；主要看每来源、任务和形式。跨领域的 `c0` 等ID不共享类别语义，因此跨领域宏F1和固定标签基线不是训练分类器基准。样本刻意含困难反例，分布不代表线上流量。
- 没有证明公共测试集未进入预训练数据。自建集针对本服务契约而设计，尚不构成经过盲测验证的通用排行榜。
