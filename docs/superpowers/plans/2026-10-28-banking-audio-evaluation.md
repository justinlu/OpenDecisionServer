# 银行音频评测实施计划

**Goal:** 创建可复现的银行机具音频意图集，实际测量Omni的办理／咨询及功能导航能力。

**Architecture:** 固定标签和统一两题，生成并冻结音频，顺序运行文本／原生音频对照，离线复算分层指标。复用现有评分器，不引入生产HTTP后端。

**Tech Stack:** Python标准库、macOS say／afconvert、llama.cpp d05706b与d1-Omni-2B Q8_0。

**Spec:** [设计与标注规则](../specs/2026-10-28-banking-audio-evaluation-design.md)。用户已明确授权创建、泛化并评测本数据集，按该范围继续执行。

- [x] 编写128条语义用例、统一问题和数据校验，独立检查标注。
- [x] 测试音频请求不泄漏转写；错误响应不移除分母；关键混淆指标可复算。
- [x] 生成两声线、噪声及声音控制，冻结音频与身份manifest。
- [x] 运行完整文本／音频、顺序敏感与重复诊断，保留原始响应。
- [x] 离线审计指标、分析失败和局限，独立审查。
- [x] 完成发布前验证，按长期授权继续合并与推送main。

结果：冻结324个WAV；主流程488请求与追加诊断324请求均无API错误。干净音频mode190/256、联合94/256；追加二类音频174/200。报告单列主分数、post-hoc、导航错误及合成数据局限；独立复算与32项工具测试通过。
